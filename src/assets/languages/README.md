# Language logos

The official logos of the languages of Temporal's SDKs, shown on the language
chips of Meet Temporal, chapter 06. Each file is the project's own artwork,
cleaned of scripts, event handlers, external references, editor data and
metadata, its viewBox cropped to the artwork where it had margins; shapes and
colors are untouched.
