# Language logos

The logos of the languages of Temporal's SDKs, shown on the language chips of
Meet Temporal, chapter 06, all drawn in one colour (ink). Each file is a
monochrome mark, cleaned of scripts, event handlers, external references,
editor data and metadata, its viewBox cropped to the artwork where it had
margins; shapes are untouched. The trademarks remain their owners'.

- `go.svg`: `go-logo-white.svg` (official) from the
  [Go brand page](https://go.dev/blog/go-brand); license: Go brand
  guidelines
- `java.svg`: `java-plain.svg` from
  [devicon](https://github.com/devicons/devicon), as Oracle publishes no
  reusable logo file; license: MIT (devicon, see `NOTICE` at the
  repository root)
- `python.svg`: `python.svg` from [Simple Icons][simple-icons]; license:
  CC0 1.0 (icon data)
- `typescript.svg`: `typescript.svg` from [Simple Icons][simple-icons];
  license: CC0 1.0 (icon data)
- `dotnet.svg`: `logo/text-only/White/dotnet-logo-text_White.svg`
  (official) from [dotnet/brand](https://github.com/dotnet/brand); license:
  CC0 1.0
- `php.svg`: `php.svg` from [Simple Icons][simple-icons]; license: CC0 1.0
  (icon data)
- `ruby.svg`: `ruby.svg` from [Simple Icons][simple-icons]; license: CC0
  1.0 (icon data)
- `rust.svg`: `rust.svg` from [Simple Icons][simple-icons]; license: CC0
  1.0 (icon data)
