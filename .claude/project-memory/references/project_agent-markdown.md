# Markdown versions for coding agents

Coding agents read each theme through its Markdown version at
`/themes/<theme>.md`, the only Markdown the site publishes: the site has
no `llms.txt` and no root index Markdown. Each file starts directly with
its `#` title (no "generated by" comment) and holds generated text only,
never hand-written prose or production notes from
`docs/<theme>/script.md` (format: README.md, Markdown versions for coding
agents).

**Why:** theme pages carry their text only inside JS scenes, so an agent
fetching `themes/<theme>/` reads almost nothing; generated text cannot
drift from the video, and the site is served at a domain root.

**How to apply:** keep `scripts/export_markdown.py` free of fixed prose
and relative links; add no other agent-facing Markdown or index without
asking.
