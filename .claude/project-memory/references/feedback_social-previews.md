# Social preview images stay current

The link preview images (`src/social.png`, `src/themes/<theme>/social.png`)
are committed and never regenerated by CI. Any change to what they show
comes with a `make social` run and the updated PNGs in the same commit:

- an intro scene (`scenes/00-intro.js`): title card, its texts, layout or
  the timing of its first subtitle (the capture time is the end of that
  subtitle)
- a shared visual drawn on a title card: `makeTitleBlock`, the logo, the
  star field, brand colors in `src/styles.css` or `src/shared.js`, the fonts
- the home page: `src/index.html` (cards, heading, lead), `src/home.css`
- a page `<title>` or `<meta name="description">` (check the image still
  matches the text)
- a new theme: its `social.png` is required, `make html` fails without it

**Why:** a stale image shows an old title card on every shared link, and
nothing in the build detects it: `make html` only copies the files.

**How to apply:** after any such change, run `make social`, look at each
changed PNG, and commit it with the change. A PNG diff with no visible
change is capture noise (a pixel off by 1, see [[project_frame-noise]]):
revert it rather than commit it.
